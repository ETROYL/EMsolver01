 # Project Summary
TinyEM is a browser-based 2D electromagnetic simulation tool. Users configure a simulation in JSON, run a finite-difference time-domain (FDTD) solver, inspect field and port results, and export data for further analysis. The solver and interface are implemented in TypeScript; the numerical results have not yet been validated against reference cases.

# Project Module Description
- **FDTD engine (`src/fdtd/`)** — Simulates TMz and TEz fields on a Yee grid, with material properties, sources, ports, boundaries, and probes.
- **Simulation interface (`src/pages/Index.tsx`)** — Edit configuration, build or reset the grid, run animated or fast simulations, view fields and plots, and export results.
- **Post-processing and export** — Computes port frequency-domain metrics and exports simulation data as JSON or CSV.
- **Blog and site pages** — Includes blog routes, article rendering, site configuration, and authentication callback/error pages.
- **UI components and utilities** — Shared interface components, hooks, and configuration/API helpers.

# Usage
From `app/frontend`:

```bash
npm install
npm run dev
```

Use the interface to edit the JSON configuration, select **Build / Reset**, then run with **Run (animated)** or **Run to end (fast)**. Export results with **Export JSON** or **Export port CSV**, or save the configuration.

Build and lint with:

```bash
npm run build
npm run lint
```

The solver supports TMz and TEz modes, material geometry, sources, lumped ports, and probes. Numerical results have not yet been checked. Known limitations include first-order Mur absorbing boundaries (no PML), no far-field or multiport S-parameter calculations, and a fast-run mode that blocks the browser UI. Exported H-probe timestamps are documented incorrectly when the sampling interval is greater than one; account for the half-timestep offset during post-processing.
