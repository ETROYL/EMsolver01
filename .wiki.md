# TinyEM 2D FDTD Solver

## Project summary

TinyEM is a browser-based 2D electromagnetic simulation tool. Users configure a TMz or TEz simulation in JSON, build a Yee grid, run an FDTD time-domain solve, inspect fields and port/probe results, and export raw data.

The numerical engine is a **research prototype**. Numerical results must be validated against analytical or trusted reference cases before being used for quantitative antenna or GPR design.

## FDTD engine

- `src/fdtd/solver.ts` — TMz/TEz Yee-grid time stepping using typed arrays.
- `src/fdtd/types.ts` — simulation schema, materials, geometry, sources, ports and probes.
- `src/fdtd/geometry.ts` — rasterises geometry onto the material map.
- `src/fdtd/waveform.ts` — Gaussian, Ricker and CW waveform generation.
- `src/fdtd/postprocess.ts` — FFT, impedance, reflection coefficient, S11 and VSWR.
- `src/fdtd/export.ts` — JSON and CSV export.
- `src/fdtd/defaultConfig.ts` — default TEz feed-gap example.

### Material placement

The field arrays use compact Nx×Ny storage but represent staggered Yee locations. Electric constitutive coefficients are locally averaged at their electric-field locations; magnetic permeability coefficients are locally averaged at magnetic-field locations. PEC samples force the corresponding tangential electric-field update coefficient to zero.

This is a local arithmetic averaging/staircase model, not conformal or sub-cell material modelling.

### Ports

Ports are finite-resistance Thévenin feeds. For x/y ports, `x,y` and optional `x1,y1` define the physical feed gap. If the second terminal is omitted, one Yee edge in the selected orientation is used.

For multi-edge gaps, source voltage and resistance are distributed in series across the gap edges. Port voltage is reconstructed from the discrete line integral of the electric field, while current is obtained from the distributed source circuit relation.

A port may not overlap PEC geometry; the default example therefore contains a real PEC gap.

### Boundaries

- PEC: tangential E is zero.
- PMC: the mode-appropriate PMC condition is explicitly applied.
- Mur: first-order absorbing boundary.

PML is not implemented.

## Post-processing and timing

Port V/I samples are aligned at the source half-step.

Probe fields retain the Yee temporal staggering. Exported probe data provides:
- `t_e`: electric-field sample time.
- `t_h`: magnetic-field sample time, offset by `-dt/2`.

S11 is calculated from the port impedance and configured reference impedance `output.z0`. Results are only meaningful after transient decay and with adequate spatial/temporal resolution.

## Usage

From the repository root:

```bash
pnpm install
pnpm run dev
pnpm run build
pnpm run lint
```

The development server is normally available at:

```
http://localhost:3000/
```

npm can execute the same scripts, but the repository's lockfile is pnpm-based. Avoid maintaining both `package-lock.json` and `pnpm-lock.yaml` as competing dependency locks.

## Validation status

Before quantitative use, validate:

1. homogeneous-medium propagation and dispersion;
2. PEC reflection;
3. dielectric-interface Fresnel coefficients;
4. Mur reflection;
5. feed-gap voltage/current against a known load;
6. impedance/S11 against a trusted reference;
7. mesh and timestep convergence.

Future capabilities include PML, far-field transformation, directivity/gain and general multiport S-parameter studies. These are not currently implemented.
